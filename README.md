# Estudos de Java

Este repositório reúne meus estudos e exercícios de programação em Java. Estou
fortalecendo novamente minha lógica de programação e aprendendo Java por meio
dos conteúdos e desafios da [DIO](https://www.dio.me/).

## Objetivos

- Retomar e praticar os fundamentos da lógica de programação.
- Aprender os conceitos da linguagem Java com exercícios práticos.
- Registrar minha evolução e manter meus estudos organizados.

## Conteúdos praticados

- Entrada e saída de dados pelo console.
- Variáveis e tipos de dados.
- Condicionais (`if` / `else`).
- Laços de repetição (`for`).
- Classificação de níveis com base em uma pontuação.

## Como executar

É necessário ter o JDK instalado. A partir da pasta do projeto, compile e
execute uma das classes:

```bash
# Aplicação de entrada e saída de dados
javac -d bin src/App.java
java -cp bin App
```

```bash
# Exercício de classificação por pontuação
javac -d bin src/ClassificacaoCredito.java
java -cp bin ClassificacaoCredito
```
